## 方法与保存边界

脚本支持 `py scripts/experiment_august_data.py --source all`；本次分别运行 `--source fuyao`、`--source ifind` 和 `--source official`，共保存 **7 份扶摇 JSON、17 份 iFinD JSON、1 份深交所半年报 PDF**。原始响应仅在 Git 忽略的 `data/raw/experiment-2026-08/`，脚本在目标文件已存在时只读取原文件、不覆盖；审计汇总另存于同目录。仓库文档只保留数量、日期、字段结构和问题，不记录行情/财务原值或密钥。`git check-ignore` 已确认原始目录被排除。

这 24 个接口请求均得到 HTTP 200：扶摇业务 `code=0`，iFinD MCP 内层业务 `code=1` 且有数据。**接口成功不代表字段、单位、期次或历史截止口径已核准。**

## 下一步

1. 为最终一年窗口建立字段清单、期次/单位/来源映射，并仅把核准后的数据发布为新的固定快照。当前两字段快照保持原样。

3. 从半年报原文核对分业务数据、产销量、产能、项目进展及减值说明；这次只下载了原文，尚未完成逐页抽取或校验。
4. 截止日锁定为 2026-08-31；2026-09-01 之后的披露或事件不得进入该版本结论。下载时间单独记录。
