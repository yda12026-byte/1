## Python 核心切片验证（2026-09-26）

原先在线取数切片执行 `py -m unittest discover -s tests -p 'test_*.py' -v`：8 项通过。覆盖同口径背离及比值输入追溯、报告期/口径不一致、缺失、零分母、接口错误、禁区文案拒绝及回退、引用与数字校验、非支持问题不调用数据源、上海时区期末转换。随后按决策 0005 改为预下载；在线取数结果仅为迁移前历史验证。

预下载版本曾执行同一命令：10 项通过，当时含七天过期测试；这是决策 0005 的历史结果。`py scripts/download_data.py` 曾真实发布两项扶摇年报字段；随后 `py scripts/diagnose_profit_cash.py` 只读快照，受限意图分类和 DeepSeek 文案校验通过。本地快照位于 Git 忽略的 `data/cache/`，受限数值没有写入仓库。

按决策 0006 改为固定快照后，同一命令再次执行：10 项通过。覆盖已存在文件拒绝覆盖、读取旧下载时间快照仍保持 `fixed`、快照 ID 回传及“实时/最新”禁区。清空金融数据密钥后运行 `py scripts/download_data.py` 返回 `already_prepared` 和原快照 ID；`py scripts/diagnose_profit_cash.py` 继续只读该快照，文案校验通过。这验证了当前两字段切片的运行路径，不代表其余字段或 Web 已完成。

迁移后的 `py scripts/probe_fuyao.py 002466.SZ` 七类请求均 `ok`；`py scripts/probe_ifind.py` 十个服务均 `ok`。这只验证当前凭据和接口结构，不等于 Web 主链路、全部 72 条候选字段或公开部署已完成。
