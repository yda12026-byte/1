# 0016：核心四维接入完整产品快照

- 日期：2026-09-26（北京时间）
- 状态：已采纳（范围与第 7 项由用户选择；计算口径细节见下，均在本记录中公开）
- 关联：决策 0013（核准口径）、0014（估值口径）、0015（Web 接口）

## 用户选择

1. 截止前先核准并接入**估值、财务趋势、行情特征、行业位置**四维，只做各维度“核心/支持”档位字段；经营质量与风险继续显示证据缺口。
2. 决策 0013 第 7 项：**公告与新闻仅作待核检索线索**。展示标题、日期（新闻附第三方链接），标明“未核准”，不进入证据或结论。

## 实施选择

- **完整产品快照**：`scripts/build_product_snapshot.py` 从 Git 忽略的一年原始文件一次性生成 `data/cache/product_snapshot_002466.json`（schema 2），内容摘要 ID、原子写入、已存在不覆盖；记录所用 142 个原始文件的 SHA-256 前缀。提问时只读，不访问金融接口。两字段旧快照继续服务四类窄问题。
- **日期**：以扶摇 002466 前复权日线的 242 个交易日为日历；估值、锂价序列按日历过滤（估值剔除 124 行、碳酸锂/氢氧化锂各 19 行、锂精矿 6 行、期货 0 行），与决策 0013 审计一致。
- **财务趋势**：比较 2026 年半年报与 2025 年半年报的累计值（0013 第 1 项）。同比 = (本期 − 基期) ÷ |基期|（0013 第 2 项），并与扶摇同名比率交叉核对，差超 0.1 个百分点标 `conflict`；基期绝对值不足本期一成时加注“倍数被放大”。经营现金流 / 净利润要求净利润为正。
- **f027 更名处理**：核实扶摇 `total_debt` = 总资产 − 所有者权益，即**负债合计而非有息债务**。因此只计算“货币资金减负债合计”并在公式中写明“不是净现金”；f027 与仅有周转率的 f030 仍保持 `pending`。
- **估值**：iFinD 截止日 PE(TTM)/PE(MRQ)/PB(MRQ)/PS/PCF 原样引用（分子 = 总股本 × A 股价，0014）；倍数 ≤ 0 为 `not_applicable`。历史分位 = 序列中不高于截止值的交易日占比，只在 iFinD 自身序列内计算；以 PB 为主，因 PE(TTM) 在半年报公告后切换分母。同行中位数取三家正式同行（0013 第 5 项）同日值。结论评价为 `neutral`，并增加禁区 `NO_VALUATION_JUDGMENT`（不得称低估、高估或便宜）。
- **行情**：观察区间、近 60/20 日涨跌幅、最大回撤、年化波动率均用前复权日收盘价**自算**（年化 = 日收益样本标准差 × √242），不用 iFinD 风险指标的周频、不复权口径。
- **相对行业**：行业收益 = 申万有色月度区间涨跌幅的复合，要求各月同为总市值加权。实测 2026-05 月窗口返回“算术平均”，因此行业复合收益标 `conflict`，相对表现结论为“暂不能计算”，不补数、不混算。
- **行业**：四类 EDB 锂价取首末交易日变化，作为行业环境证据（0013 第 4 项），不等同公司实现售价；同行毛利率、ROE、资产负债率、营收同比统一取扶摇指标接口同一报告期，四家同源。
- **LLM**：每个维度一次受限调用，逐条结论独立校验；只发送结论元数据与证据标签和状态，不发送数值。多条改写的单次超时为 30 秒，维度间并行；Gunicorn 超时调至 60 秒。结论锚点不含数字（校验器禁止正文出现数字），测试强制“回退文案包含锚点”。
- **路由**：四维单独或组合提问为 `implemented`；含未接入维度时为 `partial`，运行已接入部分并列出其余缺口；问题点名 2025、2026 以外年份时保持 `planned`；“营收”纳入财务趋势关键词。

## 补充（2026-09-26，用户页面反馈）

- **总体解读**：维度问题的回答先给一段总体解读，再列分维度卡片。LLM 只接收各维度结论锚点、类型、评价与优先级，必须逐字包含每个维度第一条已确定结论的锚点；不得有数字、禁词（含“建议”“低估”等）或超过 320 字，否则回退为程序按维度拼接锚点的汇总文本（未计算项列为“尚待核实”，未接入维度注明“未纳入”）。结论在调用 LLM 前已确定，所以总体解读与各维度改写并行生成，不明显增加等待时间。
- **颜色**：数据卡片不用红绿等带涨跌暗示的颜色。方向用蓝灰/紫灰并配 ↑ ↓ ⇅ ? 符号和文字；证据有效为蓝灰、缺失为灰、冲突为琥珀（数据质量提示，不表示涨跌）。
- **示例**：首屏只列六个维度示例，四类窄财务问题收入“更多示例”。
