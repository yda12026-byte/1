# 0004｜前端之外优先使用 Python

- 日期：2026-09-26
- 状态：已确定（用户明确指定）

## 选择

除 HTML 前端所需的 CSS、浏览器 JavaScript 外，能用 Python 实现的后端服务、金融数据适配、确定性指标计算、LLM 调用、辅助脚本与测试优先使用 Python。具体 Web 框架和部署平台尚未确定。

## 理由

这是用户对项目实现语言的明确偏好，可减少后续跨会话选型分歧，并使数据处理、服务端逻辑和测试尽量使用同一语言。

## 替代方案与影响

- 仅在 Python 明显不适用或现有依赖强制要求其他语言时使用例外，并在相关决策或工作日志说明理由。
- 现有 Node.js 权限探测脚本和工作区中可能存在的 `.mjs` 原型不因此自动删除、覆盖或认定无效；先确认所有者、工作树状态和功能，再决定是否迁移或集成。
- 后续新增产品实现遵循本选择；本记录不表示 Python Web 框架已选定，也不表示现有原型已完成迁移。
