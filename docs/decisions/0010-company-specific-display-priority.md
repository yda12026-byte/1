# 0010：天齐锂业的字段优先级与有限输出

- 日期：2026-09-26
- 状态：已采纳；完整 Web 展示及数据核准待实现

## 选择与依据

当前 72 条仍是可钻取的候选范围，但不再等量进入默认输出。为天齐锂业设独立的 `config/priority_profile_002466.json`，对每项字段给出四档展示优先级和理由：核心驱动/风险、解释与交叉验证、背景或钻取、弱化展示。四档仅控制产品编辑顺序，不是收益预测、企业评分或统计权重。

公司[2025 年年度报告](https://static.cninfo.com.cn/finalpage/2026-03-28/1225044817.PDF)披露矿端与锂化工业务，并讨论锂产品价格、锂精矿定价周期、成本传导、参股公司投资收益和减值；[2026 年半年度报告](https://static.cninfo.com.cn/finalpage/2026-08-28/1225522276.PDF)继续讨论锂精矿与碳酸锂价格变化。因此研究画像采用“锂资源与锂化工一体化”，优先串起同品级锂价、分业务量价成本、利润现金、存货减值和债务/项目资金。它不是“纯矿企”画像，也不把现货报价当公司实现售价。研发费用列为弱化展示，用户专问时仍可进入首屏。

单维问题默认最多 5 项，多维问题最多 8 项，全面诊断按七维配额最多 12 项。路由继续返回全部候选 `field_ids` 供钻取，同时以 `display_plan.default_field_ids` 返回有限首屏字段，以 `drilldown_field_ids` 返回其他字段。明确点名的字段优先于通用排序；四类已实现窄问题始终保留其计算所需的全部输入。优先级与证据状态分离：高重要度字段如产销量/均价、公告原文或锂价敏感性模型未核准时，要显示缺口，不能拿低重要度数值替代。

## 替代方案与影响

没有采用统一等权展示或看似精确的 0–100 分金融权重；当前证据不足以校准该类分数。也没有直接删除弱化字段，因为研究问题可能明确要求它们。优先级写在公司专属配置，未来更换标的必须重做业务画像、字段理由与测试。首屏规划可在[问题对照表](../question-routing-map.md)审阅；其余维度尚无完整快照，`default_field_ids` 只是未来展示计划，不表示已有有效金融结论。
