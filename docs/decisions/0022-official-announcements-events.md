# 0022 重要事件维度接入巨潮资讯官方公告

- 日期：2026-09-26
- 状态：已采用；取代决策 0013 第 7 项与决策 0016 中“公告仅作待核检索线索”的部分（新闻仍只作线索）

## 背景

事件维度此前只展示 iFinD `search_notice` 的标题与片段（无原文链接、每月最多 50 条），按 0013/0016 只能作待核线索。巨潮资讯（深交所指定信息披露网站）的公开公告查询接口对 002466 在 2025-08-31 至 2026-08-31 返回 207 条公告，每条带官方标题、披露时间和 PDF 原文链接。

## 选择（用户 2026-09-26 确认）

1. **权威来源**：公告清单与原文取自巨潮资讯；`py scripts/download_cninfo_events.py` 一次性保存清单与重要类别 PDF 到 Git 忽略的原始目录，不覆盖。
2. **九类重要事项**：定期报告、业绩预告、项目或扩产、诉讼仲裁、担保、回购、套期保值、利润分配，以及用户同日追加的“资本运作”（股权融资与可转债、对外投资、参股股权处置）。由 `src/diagnosis/events.py` 按标题规则确定性分类，不用 LLM（债务融资工具注册与付息、H 股增发一般性授权未计入资本运作）；制度、细则、章程、法律意见书、可行性分析报告、H 股公告等附件与例行文件归入“其他公告”只计数。
3. **原文摘录：程序抽取加人工抽查**（2026-09-26 首批 9 条样本全部一致；追加资本运作类后补抽 1 条）。`py scripts/extract_cninfo_events.py` 用 PyMuPDF 文本层，按每类的有序关键词取第一句原文并记页码；业绩预告另解析类型与归母净利润区间。抽查样本为每类一条摘录加全部业绩预告区间，结果由人工对照 PDF 用 `py scripts/record_event_spotcheck.py` 记录；抽查不一致的摘录标为 `conflict`，相关结论降为未知。
4. **行情图标出事件日期**：行情（或只问事件时的事件）分区显示前复权收盘价折线，九类事项的公告日期作标记，悬停看标题、点击开原文；明确写“只做时间并列，不表示因果关系”。

## 结论与口径

- 公告分类计数表（`f055`）；定期报告实际披露日与法定截止日之差（年报与一季报 4-30、半年报 8-31、三季报 10-31，`f057`）；业绩预告区间与随后定期报告归母净利润（扶摇累计利润表）的位置 `(实际 − 下限) ÷ (上限 − 下限) × 100`（`f055`）；项目或扩产、诉讼与担保、利润分配与回购、资本运作、套期保值的原文摘录（`f058`、`f055`、`f059`）。
- 全部为 `fact`；除逾期披露或预告落空为负面外，评价为中性。新增禁区 `NO_EVENT_PRICE_LINK`（不得称利好利空或把事件说成股价涨跌原因）。
- 快照新增可选的 `events` 块；没有该块的旧快照仍可运行，事件维度退回“缺口 + 检索线索”。

## 替代方案

- 继续只用 iFinD 检索片段：无原文链接与页码，不满足“关键结论能钻取到公告原文”。
- 由 LLM 读公告并分类或摘要：结果不可复现，且可能改写原文；未采用。
- 全部摘录人工确认：更稳妥但耗时，用户选择程序抽取加人工抽查。
