# 0018：经营质量与风险维度接入（官方半年报摘录）

- 日期：2026-09-26（北京时间）
- 状态：已采纳
- 关联：决策 0013、0016、0017

## 数据来源与核准

- opencode 按指定格式从 `official_stock_2026_h1.pdf`、`official_stock_2025_h1.pdf` 摘录 54 项（分产品收入/成本/毛利率、投资收益、扣非归母净利润、存货、五项有息债务、减值、存货跌价准备、资本开支、锂精矿产量、在建项目进度），每项记 PDF 页码与表名；未披露项为空值并注明，不估算。存货、借款、扣非、投资收益与 iFinD 交叉核对，两期一致；2025 半年报“应付债券”未列示（双方均无）。
- Claude Code 独立复核：两项分产品收入合计约占扶摇总营收的百分之九十九点八；毛利率与“（收入 − 成本）÷ 收入”相差不到千分之五个百分点；归母净利润与扶摇一致；抽查的存货、投资收益、长期借款、资产减值损失均在所注页码上逐字找到。
- 申万有色 2026-05 以显式“总市值加权平均”重新查询（`ifind_sector_2026_05_capweighted.json`），快照优先采用该文件，十二个月口径一致，相对行业表现不再是冲突状态。
- 摘录文件和交叉核对结果进入产品快照 `official_h1` 块并记录文件摘要；核对不一致的项目在证据中标为冲突。

## 实施选择

- **财务趋势**：f027 改为真正的净现金 = 货币资金 − 有息债务（短期借款 + 一年内到期的非流动负债 + 长期借款 + 应付债券 + 租赁负债），取代决策 0016 的“货币资金减负债合计”；补充存货金额同比（f030）与扣非归母净利润同比（f019）。
- **经营质量**（新）：分业务收入占比与毛利率（f004/f013）、两项业务毛利率同比变动、投资收益占归母净利润比重（低于百分之十“较小”、百分之十至三十“一定”、三十及以上“较大”，阈值写入公式）、锂精矿产量同比（f014，约数；销量与均价未披露）。
- **风险**（新）：流动比率同比与速动/现金比率（f063）、货币资金 ÷ 有息债务（f065）、存货跌价准备余额同比与本期减值（f069）、资本开支 ÷ 经营现金流与在建项目进度原文（f072）。锂价经营敏感性（f070）与海外敞口（f071）仍为缺口。
- **路由**：六个维度可运行，重要事件仍只列线索，全面诊断为 `partial`。“经营现金流”中的“经营”不再额外选中经营质量维度。

## 影响

- 产品快照需重新生成并重新上传云存储（文件名不变，覆盖后重启服务）。
- 以上阈值均为展示分级，不代表投资评价；结论禁区与 LLM 校验规则不变。
