# 0009：扩大固定快照可回答的财务问题

- 日期：2026-09-26
- 状态：已采纳

## 选择

在现有两项扶摇年报字段的固定快照上，增加三个受限意图：`net_profit_status`、`operating_cash_flow_status`、`profit_cash_ratio`。分别回答净利润正负、经营活动现金流净额正负，以及两者同一期同口径的比值。原 `profit_cash_alignment` 继续回答两者方向关系。每个意图有独立字段清单、确定性结论、证据链接和 `cannot_say`；单项问题不要求另一项数据有效。比值只在净利润为正且两项来源期次、口径和单位一致时计算，数字保存在可钻取的计算证据中。

时间趋势、同比、指定年份、两项绝对差额、一般估值/行业和全面财务问题仍为 `planned`；同时要求其他维度的复合问题保留多维路由，不因出现净利润词就丢掉估值或行业维度。买卖和确定性股价问题为 `unsupported`。LLM 只能选择固定意图，程序要求问题中有相应指标词，防止把不相关问题送入已实现计算。所有结论继续受 2026-08-31 数据截止日和固定快照边界约束。

## 理由与替代方案

现有快照可以可靠支持四类精确问题；直接把整个“财务趋势”维度标成已实现会让用户误以为已有同比、单季度、资产负债和经营质量证据。也可以立即补充更多数据后再扩题，但各字段的时间、单位和授权口径尚待核准。先扩大两字段可证实的问法，保持回答与证据范围一致。

## 影响与限制

新增通用命令 `py scripts/diagnose_question.py "问题"`；旧入口仍可用。配置版本升为 `002466-route-v2`，财务结论规则版本升为 `profit-cash-v2`。当前只回答固定快照中一份共同年报的单项方向、比值和方向关系；不能从这两项值推断同比趋势、利润原因、财务造假或投资操作。其余维度仍需完整数据快照与各自计算规则。
