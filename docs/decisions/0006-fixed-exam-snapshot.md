# 0006｜考试产品使用一次性固定快照

日期：2026-09-26

状态：已确定（用户明确调整范围）；取代 [0005](0005-preloaded-data.md) 的刷新、过期和服务器数据库计划

## 选择

这是一次性考试产品。把实际需要且已核准的数据下载一次，形成固定快照；运行时只读取该快照，不设置定时更新、七天过期或服务器数据库。每次诊断展示并引用同一个 `snapshot_id` 和数据下载时间。下载脚本遇到已存在快照时直接返回其 ID，不再次调用金融数据接口；存储层拒绝覆盖已有文件。

当前实现仍只是两项扶摇年报字段的首条诊断切片。其余维度所需的扶摇及 iFinD 字段要在映射、时点和口径核准后一次性准备，并形成新的完整固定快照；不能把当前两字段快照称作最终产品数据集。

## 理由

项目交付后不计划持续使用。固定快照足以让评审实际操作、复现同一结论，也避免引入与题目核心无关的刷新调度、失效策略和数据库维护。

## 影响与边界

- 产品所有“当前状态”表达都必须改为“截至快照时间/报告期”，不得把固定快照称为实时或最新数据。结论对象加入 `NO_LIVE_DATA` 禁区，LLM 文案不通过时回退到确定性文本。
- 快照保留内容摘要、来源定位、报告期、单位及计算输入；读取时检验摘要和结构，不因时间推移改变原始值。源字段本身缺失、冲突或未核准仍按相应状态处理。
- 受限数据快照位于 Git 忽略目录，不进入公开仓库。部署时可通过 `DIAGNOSIS_SNAPSHOT_PATH` 指向服务器私有文件；正式上传/展示前须核实相应数据授权。部署方案尚未选定。
- 若发现数据或口径错误，应生成新文件和新版本 ID，经人工核验后切换部署引用；不修改已冻结的文件。
