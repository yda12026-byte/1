# 0013 一年数据核准口径与同行组

日期：2026-09-26（北京时间）
状态：第 1–6、8、9 项已决定；第 7 项（公告/新闻呈现方式）暂缓
适用范围：天齐锂业 `002466.SZ`，一年原始数据窗口 2025-08-31 至 2026-08-31，数据截止日 2026-08-31

## 背景

用户要求在核准已下载的一年数据时，把拿不准或需要口径选择的地方列出，不得自行决定。交接先输出“已核准 / 待核 / 需要用户决定”三类清单，再逐项确认。本记录保存用户对 9 项的口径决定，以及接手会话独立复核到的事实。原始响应仍只在 Git 忽略目录，本记录不含受限数值。

## 决定

1. **扶摇季度报表按累计值使用并标注“累计”**，不用相邻累计值相减推导单季。受影响字段：`f005` `f006` `f008` `f011` `f021` `f022` `f025`；由它们计算的 `f009` `f011` `f024` `f026` `f065` 注明“基于累计期”。`f020` 单季度利润只取 iFinD 的单季度字段，不再从扶摇推算。
2. **负基期归母净利润同比采用绝对基期算法并注明**；营业利润同比在近零基期同样加注。受影响字段：`f018` `f017`。
3. **估值、行业、价格序列统一按实际交易日过滤**（以扶摇 242 个交易日历为准），非交易日一律剔除；假日工作日的现货锂价也剔除。受影响字段：`f039` `f045` `f049` `f050` `f051` `f052` `f054` `f067`。
4. **EDB 锂价作为行业环境证据**，不作为交易信号，也不等同于公司实现售价或销售均价。受影响字段：`f050` `f051` `f052`；`f070` 经营敏感性仍未核准。
5. **正式同行组采用三家**：赣锋锂业 `002460.SZ`、中矿资源 `002738.SZ`、永兴材料 `002756.SZ`（“资源＋锂盐冶炼一体化”口径）。受影响字段：`f003` `f040` `f053` `f054`。新增两家需要补一次同日估值、同区间前复权行情、同报告期财务的下载。
6. **iFinD 估值 TTM/MRQ 口径先确认再展示**：逐列核实分子市值口径、分母期间、是否年化、负值处理、更新时点，并用已知财报复算；通过后写入数据契约并标 `valid`。未确认前不得做跨来源比较、分位或高低判断。受影响字段：`f034` `f035` `f036` `f037` `f038` `f039` `f040` `f054`。
7. **公告与新闻的呈现方式暂缓决定**：仅作“待核检索线索”展示，还是补原文后作正式事件证据，待定。受影响字段：`f055` `f058` `f062`。在该项决定前，事件类检索结果不得进入正式事件事实。
8. **扶摇除复权事件 `code=3002` 显示为“该请求范围无匹配事件”**，不得写成“没有分红/送股/配股”。受影响字段：`f059`。
9. **个股异动原因保留为历史数据缺口**：首屏不作当期结论，保留钻取入口。受影响字段：`f048`。

## 本次接手独立复核到的事实

### 扶摇 `report_date_ms` 不是披露日
接口返回的 `report_date_ms` 呈现“该期次在最新一期同类报告中的出具日”特征，而非该期实际披露日。例：`2025-06-30` 行的 `report_date_ms` 等于 2026-08-28（2026 半年报披露日），`2024-06-30` 行等于 2025-08-29。实际披露日必须以官方公告核准。

### iFinD 财务查询的报告期语义冲突
- `financial_2025_h1` / `financial_2026_h1` 各行日期分别为 2025-06-30 / 2026-06-30，但 `indicators_params` 中多项写 `报告期: 最新一期(MRQ)`。
- `business_2026_h1` 与 `financial_2025_fy` 的分业务字段写 `报告期: 去年年报`；即 2026 半年报请求返回的实际是上一年年报口径，需按返回日期与字段逐行过滤。
- 同一返回内季度标签还会不一致：`financial_2026_h1` 中 `单季度.净利润` 标“第二季度”，`单季度.归母净利润` 标“第一季度”。**2026-09-26 复核**：以扶摇累计值相减核对，天齐 `单季度.归母净利润` 与中矿资源 `单季度.营业收入`（同样标“第一季度”）的数值均等于第二季度单季（H1 累计 − Q1 累计，比值 1.0000）；“第一季度”标签错误，数值属于第二季度。H1 累计营收 iFinD 与扶摇一致。
- 结论：不能仅凭查询问题文字认定报告期，必须按返回日期、`indicators_params` 与字段逐行核对。

### 检索与资料来源结构
- `search_notice` / `project_notices` 返回 `公告标题`、`公告片段内容`、`日期`，**没有 URL**；`search_news` 返回 `资讯标题`、`资讯内容`、`日期`、`URL`，但属第三方资讯，不是公司公告。
- `get_stock_events` 文本写明“为您找到 366 条数据，以下为部分数据”，返回被截断，且含 2026-09-30 等窗口外日期，不能当作窗口内完整事件清单。
- `get_stock_info` 返回可比公司 `Albemarle、FMC、Orocobre、SQM、江西赣锋锂业`，竞争公司 `南京寒锐钴业、四川雅化实业集团` 等；项目在此基础上另定三家 A 股同行。

### 风险与行业指标口径
- 风险指标元数据：波动率为“周计算周期、普通收益率”，最大回撤为“不复权”（与日线前复权不一致），须标窗口与复权口径。
- 行业序列为“成份区间涨跌幅（总市值加权平均）＋收盘价（算术平均）＋成份股数”，元数据成份股数 145。

### 日期轴对比（决定 3 的依据）
以扶摇个股日线 242 个交易日为基准：

| 序列 | 有日期行 | 周末行 | 落在交易日历 | 假日工作日 | 交易日缺口 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 估值 | 366 | 105 | 242 | 19 | 0 |
| 行业 | 366 | 105 | 242 | 19 | 0 |
| 碳酸锂现货 | 261 | 0 | 242 | 19 | 0 |
| 氢氧化锂现货 | 261 | 0 | 242 | 19 | 0 |
| 锂精矿 | 248 | 6 | 242 | 0 | 0 |
| 碳酸锂期货 | 242 | 0 | 242 | 0 | 0 |

- 366 个自然日 = 242 交易日 + 19 个休市工作日 + 105 个周末日；19 天为国庆、元旦、春节、清明、五一、端午等休市日。
- 估值、行业的周末行是上一交易日值的复制，会产生零收益行，系统性影响波动率与分位。
- 碳酸锂、氢氧化锂为“工作日频率”，锂精矿混周末（含调休补班日），碳酸锂期货恰为交易日频率。

## 替代方案与影响

- 累计值方案放弃“相邻累计相减得单季”，换取与官方报告口径一致、可复核；代价是单季利润只能依赖 iFinD 单季度字段。
- 交易日过滤放弃“保留自然日但标注”，换取跨序列同日可比；代价是丢掉“A 股休市但现货有报价”的真实现货观测。
- 同行组选“资源＋冶炼一体化”三家；若后续改选锂盐加工组或全球可比组，须新建决策记录取代本节第 5 项。
- 估值口径先确认意味着估值结论出现较晚，但避免“同名不同义”的误读。
