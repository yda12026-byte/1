# 0019：超范围问题改为说明原因并推荐问题；路由与口径修正

- 日期：2026-09-26（北京时间）
- 状态：已采纳（用户要求）
- 关联：决策 0009、0015、0016

## 选择

1. **超范围问题不再直接拒答**：命中买卖、预测或收益承诺类用语时，路由分类为“买卖或持仓建议”“股价涨跌预测”“收益承诺”（可多选）。回答格式为：“您的提问涉及 X，超出本模型能力范围。本模型只基于截至 2026-08-31 的固定数据，对天齐锂业的六个维度做有证据的诊断……不提供投资建议、涨跌预测或收益承诺。”随后附三到四个可点击的推荐问题（总是包含“全面诊断”）。无法识别的问题回答“暂时无法识别您的问题”，同样附推荐问题。不读取数据，不调用 LLM，也不给出任何方向性意见。测试保证每个推荐问题都能被正常回答。
2. **锂价走势归入行业位置**：问题含锂价、碳酸锂、氢氧化锂或锂精矿，且没有点名股价、行情、成交、回撤时，“走势 / 涨跌 / 波动”不再额外选中行情特征。
3. **窄财务问题注明口径**：四类窄问题读两字段快照（2025 年年报），每条结论的限制说明末尾加“按 2025 年年报口径；2026 年半年报的对比可问‘财务趋势’”，避免与维度诊断（2026 年半年报累计）混淆。暂不把窄问题改为半年报，以免牵动已验证的两字段快照和测试。

## 理由

- 合规边界不变，但用户得到的是可以继续使用的引导，而不是一句拒绝。
- 路由与口径修正都来自对实际问法的实测。
