# 0017：公开展示数据许可与不设限流

- 日期：2026-09-26（北京时间）
- 状态：已采纳（用户确认）
- 关联：决策 0012（CloudBase 部署）、0016（完整产品快照）

## 选择

1. **公开展示许可**：用户确认，笔试提交的公开 Web 页面可以免登录展示来自扶摇、iFinD 与官方报告的数值及其派生计算结果（估值倍数、股价与涨跌幅、财报金额、锂价、同行指标等）。原始批量响应仍不进入 Git、镜像或前端；快照仍只由服务端读取。
2. **不设接口限流**：公开地址不加按 IP 的请求限流。每次维度提问会调用 DeepSeek（每维一次改写，另加一次总体解读），费用由用户的 DeepSeek 额度承担。

## 理由与替代方案

- 题目要求提交可访问、可操作的 Web URL，评审需要不登录即可看到证据数值。
- 限流可防止刷接口消耗额度，但用户选择不加，以免误伤评审操作；如需要可在 `webapp.py` 增加内存级限流，另行记录。

## 影响

- 部署清单中的“核准数据保存/展示授权”视为已完成。
- 上线后若发现异常流量，可临时在 CloudBase 控制台缩容或停止服务，再决定是否加限流。
